Ek line mein: "Maine exactly mask cities visit ki hain, aur last mein city i pe hoon — minimum cost kya hai?"

State: dp[mask][i] = min cost to visit cities in mask, ending at city i
Transition: city i ko mask se hataao → prev = mask ^ (1<<i), phir kisi j se aaye the
Recurrence
dp[mask][i] = min over all j in prev_mask: dp[prev][j] + dist[j][i] where prev = mask ^ (1 << i) (remove city i from mask) Base: dp[1<<i][i] = 0 (start at city i, only city i visited) Answer: min over i: dp[full_mask][i] + dist[i][0]

def tsp(dist, n): INF = float('inf') dp = [[INF]*n for _ in range(1<<n)] dp[1][0] = 0 # start at city 0 for mask in range(1, 1<<n): for i in range(n): if not (mask >> i & 1): continue if dp[mask][i] == INF: continue prev = mask ^ (1 << i) for j in range(n): if not (prev >> j & 1): continue dp[mask][i] = min(dp[mask][i], dp[prev][j] + dist[j][i]) full = (1<<n) - 1 return min(dp[full][i] + dist[i][0] for i in range(n))

def domino_tiling(n): # rows=2, so profile is a 2-bit mask dp = [0] * (1 << 2) # dp[profile of next col] dp[0] = 1 # empty grid, nothing pre-filled def fill(col_profile, next_profile, row, ways): # try to fill current column given what's pre-filled if row == 2: # all rows of column done new_dp[next_profile] += ways return if col_profile >> row & 1: # cell already filled fill(col_profile, next_profile, row+1, ways) else: # place vertical tile (fills this row only) if row+1 < 2 and not (col_profile >> (row+1) & 1): fill(col_profile, next_profile, row+2, ways) # place horizontal tile (spills into next col) fill(col_profile, next_profile | (1<<row), row+1, ways) for _ in range(n): new_dp = [0] * (1 << 2) for prof in range(1 << 2): if dp[prof]: fill(prof, 0, 0, dp[prof]) dp = new_dp return dp[0]
Ek line mein: Har mask ke liye, uske saare subsets ka sum/max/min efficiently compute karo — O(N·2^N) mein, brute force O(3^N) ke bajaye.

Idea: DP by bit position — pehle bit 0 consider karo (har mask update karo jo bit 0 mein 1 hai), phir bit 1, etc. Yeh inclusion ke "dimensions" hain.
The SOS DP transition (dimension by dimension)
# f[mask] = sum of a[sub] for all sub ⊆ mask f = a[:] # base: f[mask] = a[mask] itself for i in range(n): # for each bit dimension for mask in range(1 << n): if mask >> i & 1: # only if bit i is SET in mask f[mask] += f[mask ^ (1 << i)] # mask without bit i is a subset of mask # add its already-computed contribution
Dry run — N=3, a=[1,0,0,2,0,3,0,4], compute f for all masks

Why this works — the intuition
After processing bit i: f[mask] = sum of a[sub] for all subsets sub of mask that differ from mask only in bits 0..i.

After processing all N bits: f[mask] = sum over ALL subsets. Classic "dp on subsets" logic — each dimension doubles the coverage.
Ek line mein: N items ko N people mein assign karo (one-to-one) with minimum cost — dp[mask] = min cost jab popcount(mask)-th person ko assign karna ho, aur mask = already assigned items ka set.

Key insight: popcount(mask) directly batata hai ki hum kaunse person ke liye assign kar rahe hain (0-indexed).

# Assign N tasks to N workers, min total cost dp[mask] = min cost when tasks in 'mask' are assigned (to workers 0..popcount(mask)-1) # Transition: which task to give to next worker? person = bin(mask).count('1') # current worker index for task in range(n): if mask >> task & 1: continue # already taken new_mask = mask | (1 << task) dp[new_mask] = min(dp[new_mask], dp[mask] + cost[person][task]) # Answer: return dp[(1<<n) - 1]

def min_cost_assignment(cost, n): INF = float('inf') dp = [INF] * (1 << n) dp[0] = 0 for mask in range(1 << n): if dp[mask] == INF: continue person = bin(mask).count('1') if person == n: continue for task in range(n): if mask >> task & 1: continue new_mask = mask | (1 << task) dp[new_mask] = min(dp[new_mask], dp[mask] + cost[person][task]) return dp[(1<<n)-1]
