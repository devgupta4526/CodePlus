# 3. Coordinate Geometry

---

## 1. Cartesian Plane & Distance Formula

- **Distance Formula**: The straight-line distance between $P(x_1, y_1)$ and $Q(x_2, y_2)$ is:
  $$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

---

## 2. Section, Mid-Point & Centroid Formulas

- **Internal Section Formula** ($m : n$ ratio):
  $$x = \frac{m x_2 + n x_1}{m + n}, \quad y = \frac{m y_2 + n y_1}{m + n}$$
- **Centroid of Triangle** ($G$):
  $$G(x, y) = \left(\frac{x_1 + x_2 + x_3}{3}, \frac{y_1 + y_2 + y_3}{3}\right)$$

---

## 3. Slopes and Equations of Straight Lines

- **Slope ($m$)**: $m = \tan \theta = \frac{y_2 - y_1}{x_2 - x_1}$. For perpendicular lines: $m_1 \times m_2 = -1$.
- **Perpendicular Distance from Point to Line**: Distance from $(x_1, y_1)$ to $Ax + By + C = 0$ is:
  $$d = \frac{|A x_1 + B y_1 + C|}{\sqrt{A^2 + B^2}}$$
