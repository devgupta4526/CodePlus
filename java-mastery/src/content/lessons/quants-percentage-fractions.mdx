## 2. Successive Percentage Change & Consumption Rules

- **Successive Change**: $\text{Net } \% = X + Y + \frac{X \times Y}{100}$
- **Fixed Expenditure Consumption Reduction**: If commodity price rises by $R\%$, consumption must drop by $\frac{R}{100 + R} \times 100\%$ to keep total cost unchanged.
