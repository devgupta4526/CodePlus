# Spelling Rules

> [!TIP]
> Spelling questions are absolute scoring areas. Memorizing a few basic rules will help eliminate standard errors.

## Rule 1: 'I' before 'E' except after 'C'
When the sound is like 'ee' (as in *see*):
* **Use 'ie':** Believe, Chief, Piece, Thief.
* **Except after 'C' (use 'ei'):** Receive, Deceive, Ceiling, Receipt.

*Exceptions:* Weird, Seize, Protein.

## Rule 2: Dropping the final 'E'
If a word ends in a silent 'e', drop the 'e' when adding a suffix that begins with a vowel.
* Hope + ing = Hoping
* Make + ing = Making
* Write + ing = Writing

*Keep the 'e' if the suffix begins with a consonant:*
* Hope + ful = Hopeful

## Top Commonly Misspelled Words

1. **Accommodation** (Double c, double m)
2. **Embarrass** (Double r, double s)
3. **Vacuum** (One c, double u)
4. **Separate** (Sep-A-rate, not sep-E-rate)
5. **Definitely** (Defin-i-tely)
6. **Committee** (Double m, double t, double e)
7. **Lieutenant** (Lieu-ten-ant)
8. **Receive** (Rule: e before i after c)

> [!WARNING]
> Many students confuse **Lose** (fail to win) and **Loose** (not tight).
