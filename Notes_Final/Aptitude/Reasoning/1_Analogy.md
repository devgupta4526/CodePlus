# 1. Analogy

---

## 1. Introduction to Analogy

**Analogy** means 'similarity' or 'matching relationship'. In reasoning, analogy questions test your ability to understand the relationship between a pair of elements and apply the identical relationship to find the missing element in another pair.

The standard format is: 
**A : B :: C : ?**
*(A is related to B in the same way as C is related to D)*

---

## 2. Types of Analogies

### A. Number Analogy
Finding the mathematical relationship between numbers. Common logic patterns include:
- **Squares & Cubes**: e.g., $4 : 16 :: 5 : 25$ ($x : x^2$)
- **Multiplication/Division**: e.g., $8 : 24 :: 12 : 36$ ($x : 3x$)
- **Prime Numbers**: e.g., $2 : 3 :: 5 : 7$ (Consecutive primes)
- **Complex Operations**: e.g., $6 : 42 :: 8 : 72$ ($x : x^2 + x$)

### B. Alphabet/Letter Analogy
Finding patterns based on the English alphabet's positional values (A=1, B=2, ..., Z=26).
- **Forward/Backward Shifts**: e.g., $BCE : EGH :: PQR : STU$ (Shift +3)
- **Opposite Letters**: e.g., $AZ : BY :: CX : DW$ (Sum of positions = 27)
- **Vowel/Consonant Patterns**: Based on alphabetical logic rather than numerical shift.

### C. Word/General Knowledge Analogy
Testing vocabulary, science, geography, and general awareness.
- **Worker and Tool**: e.g., *Blacksmith : Anvil :: Carpenter : Saw*
- **Quantity and Unit**: e.g., *Force : Newton :: Current : Ampere*
- **Country and Capital**: e.g., *Japan : Tokyo :: France : Paris*
- **Study and Topic**: e.g., *Botany : Plants :: Ornithology : Birds*

---

## 3. Important Tips to Solve Analogy Fast

1. **Memorize Alphabetic Positions**: Know both forward (A=1, Z=26) and backward (A=26, Z=1) positions of letters.
2. **Remember Opposites**: A-Z, B-Y, C-X, D-W, E-V, F-U, G-T, H-S, I-R, J-Q, K-P, L-O, M-N.
3. **Master Squares & Cubes**: Memorize squares up to 30 and cubes up to 15.
4. **Identify the Core Logic**: Don't jump to conclusions. Check if the logic holds perfectly for the second pair. Sometimes multiple logics exist; choose the one most mathematically sound.
