## 1. Complete 3D Solid Geometry Formula Table

| Solid Name | Volume ($V$) | Curved/Lateral Surface Area | Total Surface Area (TSA) |
| :--- | :--- | :--- | :--- |
| **Cuboid** | $V = L \times B \times H$ | $\text{LSA} = 2H(L + B)$ | $\text{TSA} = 2(LB + BH + HL)$ |
| **Cube** | $V = a^3$ | $\text{LSA} = 4a^2$ | $\text{TSA} = 6a^2$ |
| **Right Cylinder**| $V = \pi r^2 h$ | $\text{CSA} = 2\pi r h$ | $\text{TSA} = 2\pi r(h + r)$ |
| **Right Circular Cone**| $V = \frac{1}{3}\pi r^2 h$ | $\text{CSA} = \pi r l$ ($l=\sqrt{r^2+h^2}$) | $\text{TSA} = \pi r(l + r)$ |
| **Sphere** | $V = \frac{4}{3}\pi r^3$ | $\text{CSA} = 4\pi r^2$ | $\text{TSA} = 4\pi r^2$ |
| **Hemisphere** | $V = \frac{2}{3}\pi r^3$ | $\text{CSA} = 2\pi r^2$ | $\text{TSA} = 3\pi r^2$ |
