# 4. Mensuration 2D: Perimeters & Areas

---

## 1. Comprehensive 2D Figures Reference Table

| Figure Name | Perimeter ($P$) / Circumference ($C$) | Area ($A$) Formula |
| :--- | :--- | :--- |
| **Rectangle** | $P = 2(L + B)$ | $A = L \times B$, Diagonal $d = \sqrt{L^2 + B^2}$ |
| **Square** | $P = 4a$ | $A = a^2 = \frac{d^2}{2}$, Diagonal $d = a\sqrt{2}$ |
| **Rhombus** | $P = 4a = 2\sqrt{d_1^2 + d_2^2}$ | $A = \frac{1}{2} \times d_1 \times d_2 = a \times h$ |
| **Trapezium** | $P = a + b + c + d$ | $A = \frac{1}{2} \times (a + b) \times h$ |
| **Equilateral Triangle**| $P = 3a$ | $A = \frac{\sqrt{3}}{4} a^2$, Height $h = \frac{\sqrt{3}}{2} a$ |
| **Circle** | $C = 2\pi r = \pi d$ | $A = \pi r^2 = \frac{\pi d^2}{4}$ |

---

## 2. Pathway Area Shortcuts

For rectangular field of length $L$ and breadth $B$, with uniform track width $W$:
- **Path outside perimeter**: $\text{Area} = 2W(L + B + 2W)$
- **Path inside perimeter**: $\text{Area} = 2W(L + B - 2W)$
