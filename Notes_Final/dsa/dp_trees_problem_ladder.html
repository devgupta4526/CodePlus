Tier 1 — Tree DP Foundations
Diameter of Binary Tree
EasyTree DP basics LeetCode 543
Concept: dp[node] = longest path through node = left_depth + right_depth.
Hinglish: Har node pe socho: left subtree ki max depth + right subtree ki max depth = diameter through this node. Global max track karo.
Binary Tree Maximum Path Sum
HardTree DP basics LeetCode 124
Concept: At each node, two choices: extend path upward (return max(left,right)+val) or close path here (ans = left+right+val).
Hinglish: DFS mein "upar kya return karein" aur "yahan close karein" — do alag values track karo.
House Robber III
MediumTree DP with states LeetCode 337
Concept: dp[node] = pair(rob_this, skip_this). If you rob node, you can't rob children.
Hinglish: Har node pe do states rakho: "is node ko liya" ya "nahi liya". Children se dono values lao aur combine karo.
Subtree of Another Tree (size/hash DP)
EasySubtree DP LeetCode 572
Concept: Compute a hash/value for each subtree bottom-up. Compare.
Hinglish: Leaf se upar hash banate jao. Same hash = same subtree. O(N) possible.
Longest Path in Tree
MediumTree DP basics Codeforces / custom
Concept: dp[node] = longest downward path. Use two largest children for diameter.
Hinglish: Diameter of tree ka generalized version — weighted tree pe bhi same trick chalti hai.
Tier 2 — Classic Tree DP Patterns
Number of Nodes in Subtree
EasySubtree sizes Prerequisite for rerooting
Concept: sz[node] = 1 + sum(sz[children]). The simplest tree DP — master this first.
Hinglish: Yeh rerooting ka building block hai. Pehle yeh achhe se samjho.
Sum of Distances in Tree
HardRerooting DP LeetCode 834 ⭐ Classic
Concept: THE classic rerooting problem. Pass 1: sum of distances from root. Pass 2: when you move root from u to neighbor v, distances to v's subtree decrease by sz[v], rest increase by (N - sz[v]).
Hinglish: Rerooting ka sabse pehla problem. Isko samjho toh sab samajh aayega. ans[v] = ans[u] - sz[v] + (N - sz[v]).
Distribute Coins in Binary Tree
MediumTree DP — flow LeetCode 979
Concept: excess[node] = coins_in_subtree - nodes_in_subtree. Moves = sum of |excess| over all edges.
Hinglish: Har edge pe kitne coins pass hone chahiye — yeh subtree DP se nikaalo.
Maximum Product of Splitted Binary Tree
MediumSubtree sums LeetCode 1339
Concept: For each edge cut, product = subtree_sum × (total - subtree_sum). Precompute all subtree sums.
Hinglish: Pehle total sum nikalo. Phir har subtree sum nikalo (tree DP). Best split dhundho.
Count Nodes Equal to Average of Subtree
MediumSubtree DP LeetCode 2265
Concept: Return (sum, count) pair from each subtree. Check if sum/count == node.val.
Hinglish: Har subtree se (sum, size) return karo — pair return karna tree DP ka common trick hai.
Tier 3 — Rerooting Deep Dive
Count Nodes with More Connections on One Side
MediumRerooting LeetCode 2858 / similar
Concept: Use sz[] (subtree sizes) + rerooting to get "nodes on each side" for every node.
Hinglish: Rerooting se har node ke liye pata chalega ki kitne nodes uske upar hain, kitne neeche.
Find the Center of a Tree (min eccentricity)
MediumRerooting — max depth CF 708C or similar
Concept: For each node as root, find max distance to any leaf. Rerooting gives O(N).
Hinglish: down[] = max depth downward. up[] = max depth if we go "upward via parent". Combine karo.
Number of Good Paths (Rerooting variant)
HardRerooting + counting LeetCode 2421
Concept: Count paths where max value = endpoint values. DSU + tree DP.
Hinglish: Edges ko value ke order mein add karo (DSU). Har component mein matching-value nodes count karo.
Rerooting: Maximum Score After Changing Connections
HardRerooting LeetCode 2538
Concept: ans[node] = sum_of_subtree_values if this node were root. Pure rerooting.
Hinglish: Har node ko root maan ke tree ka total "score" nikalna — classic rerooting se O(N) mein.
CF 1822G — Replacing Ith Edge
HardRerooting on edges Codeforces 1822G
Concept: For each edge, compute contribution if it's removed. Rerooting on edges.
Hinglish: Nodes ke bajaay edges pe rerooting karo — slightly tricky but same idea.
Tier 4 — DAG DP & Advanced
Longest Path in DAG
MediumDAG DP — topo sort Classic problem
Concept: Topological sort → DP in topo order. dp[u] = max(dp[v]+1) for all edges u→v.
Hinglish: Pehle topo sort karo (BFS ya DFS). Phir uski order mein dp karo. Tree DP ka DAG version.
Count Paths in DAG / Number of Ways to Reach Destination
MediumDAG DP — counting LeetCode 1976 (ways variant)
Concept: ways[node] = sum of ways[predecessor]. Process in reverse topo order.
Hinglish: Kitne raaste hain — DAG mein DP se count karo. dp[destination]=1, baaki topo reverse mein.
CF 839C — Journey
HardTree DP + probability Codeforces 839C
Concept: Expected value DP on tree. At each node, decide to stop or go deeper.
Hinglish: Probability tree DP — dp[node] = expected score. Har node pe "ruko ya aage jao" ka decision.
Tree DP with Knapsack — CF 161D / CF 1033E
HardTree knapsack O(N²) tree DP
Concept: Each node has a "budget" and merging subtrees is a knapsack. Key insight: total work is O(N²) due to small-large merging.
Hinglish: Har subtree ek knapsack hai. Children merge karte waqt sizes ka product total O(N²) hota hai — this is the "tree knapsack" trick.
Minimum Vertex Cover / Maximum Independent Set on Tree
MediumTree DP — classic combinatorics
Concept: dp[node][0/1] = min cover / max independent set if node is included or excluded.
Hinglish: Yeh graph theory ka ek classic hai trees pe. dp[node][0] = node nahi liya, dp[node][1] = liya. Children se transitions simple hain.
